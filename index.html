Introduction to Web Design

Web design is the process of planning and creating the look, layout and feel of a website. It combines visual design, user experience, and technical skills so that a website is attractive, easy to use, and works well on phones, tablets and computers.

Every website you visit, from a school page to an online store, started as a design: someone decided where the menu goes, which colors to use, how big the text should be, and how visitors will move from page to page.

Key Principles of Good Web Design

  • Simplicity: Keep pages clean so visitors find what they need quickly.
  • Consistency: Use the same colors, fonts and layout across all pages.
  • Responsive design: The site should look good on every screen size.
  • Readability: Choose clear fonts and strong contrast between text and background.
  • Easy navigation: Menus and links should be obvious and logical.
  • Speed: Optimized images and light code make pages load fast.

Web Technologies Explained

Websites are built with a few core technologies that work together. Think of a house: HTML is the structure, CSS is the paint and decoration, and JavaScript is the electricity that makes things work.

Technology What It Does Simple Example
HTML (HyperText Markup Language) Creates the structure and content of a page: headings, paragraphs, images, links, tables. <h1>Hello</h1>
CSS (Cascading Style Sheets) Controls the look: colors, fonts, spacing, layout and responsiveness. h1 { color: blue; }
JavaScript Adds interactivity: menus, forms, animations, and updating content without reloading. alert("Welcome!");
HTTP / HTTPS The rules browsers and servers use to send web pages; HTTPS adds encryption for security. https://example.com
Web Server & Hosting A computer that stores your website files and delivers them to visitors. Shared hosting, cloud hosting
Domain Name (DNS) Turns a friendly name into the address of the server where the site lives. mysite.com

How a Website Loads

  1. You type a web address into your browser.
  2. DNS finds the server that hosts that website.
  3. The browser asks the server for the page using HTTP/HTTPS.
  4. The server sends back HTML, CSS, JavaScript and images.
  5. The browser puts it all together and shows you the page.
